# Usage example for 'Interconnect RTL Based on Opened Spec' blueprint

1. Run in terminal: `cp .dvt/ai/examples/interconnect_rtl/dma.v.empty designs/socv/rtl/rtl_lpw/dma/rtl/dma.v`
2. Refresh & run a DVT Build
3. Open: `designs/socv/rtl/rtl_lpw/dma/rtl/dma_interconnect_spec.md`
   - NOTE: Depending on your settings, Eclipse may open it in an external editor, if that happens, 
   right-click the file and select Open With → Plain Text Editor to open it directly within Eclipse 
4. Start a New Session from Blueprint: `Interconnect RTL Based on Opened Spec`
